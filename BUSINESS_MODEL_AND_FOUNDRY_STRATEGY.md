## 5. Technical Standard & The 5 Immutable Laws

Every application produced across the entire 500-to-5,000 roadmap must satisfy the strict **Ghost Factory™ 9.0+ Minimum Gate**:
1. **Obsidian Dark-Mode Aesthetic**: High-contrast typography, `#0A0A0B` / `#050505` obsidian palette, responsive layout, zero placeholder text.
2. **Automated Media HEAD Ping**: 100% of photographic assets and endpoints must return HTTP `200 OK`.
3. **Turnkey Database Wiring**: Every template includes an isolated `schema.sql` (with RLS), `seed.sql` dataset, and a 3-minute `SUPABASE_SETUP.md`.
4. **Frictionless Demo Gate**: Every system MUST include an `/admin` route or header action with a 1-click auto-fill passkey (`<slug>2026`).
5. **Standardized Directory Packaging**: Every build must output an isolated bundle in `dist/<slug>/` containing `<slug>-v1.0.0.zip`, 16:9 cover banner, and 1:1 storefront icon.
